## Что сделано в работе

- Сравнены семь фаззеров — bBOXRT, EvoMaster, RESTest, RestCT, RESTler, RestTestGen и Schemathesis — на 19 REST API общим объёмом более 280 000 строк бизнес-логики; для анализа обнаружения дефектов дополнительно использован искусственный API с 10 внедрёнными дефектами.
- Все инструменты запускались с лимитом в один час и десятью повторениями (всего 1 330 прогонов); для лучших инструментов проверены также лимиты 6 минут и 10 часов. Покрытие строк измерялось через JaCoCo для JVM и c8 для NodeJS — как в режиме чёрного, так и в режиме белого ящика.
- Лучшие результаты в среднем показали EvoMaster (56,8% покрытия строк) и Schemathesis (54,5%); ни один фаззер чёрного ящика не превысил 60%, а 100% покрытия удалось достичь лишь в одном случае из 19 API. Тестирование методом белого ящика дало более высокое покрытие, но значительные части API остались непокрытыми.
- Анализ логов инструментов и исходного кода API выявил шесть классов открытых проблем: аутентификация, работа с базами данных, внешние сервисы, несоответствия схемы, ограничения на строковые данные и недостижимый код.
