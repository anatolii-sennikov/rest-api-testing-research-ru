## Что сделано в работе

- AutoRestTest сочетает граф зависимостей семантических свойств (SPDG), мультиагентное обучение с подкреплением (MARL) с четырьмя специализированными агентами и генерацию значений большой языковой моделью (LLM). Вместе эти компоненты позволяют исследовать большие пространства входных данных REST API методом чёрного ящика.
- В REST League на SBFT 2026 инструмент занял первое место во всех трёх категориях: обнаружение дефектов, общая эффективность и общая результативность.
- На 11 реальных REST API с 317 операциями (примерно 29 на API) при часовом бюджете и десяти прогонах среднее число уникальных ошибок 5xx составило 67,09, а среднее число успешно выполненных операций — 17,27 на API. Это в 2,7 раза больше дефектов, чем у занявшего второе место инструмента (24,65); AUC обнаружения дефектов — 151 490 против 66 761.
- Средняя стоимость прогона для одного сервиса — около 0,02 долл. США; всего израсходовано примерно 9,6 млн входных и 2,2 млн выходных токенов. На API flight-search произошёл сбой: парсер ответов предполагал, что все ответы используют UTF-8. В дальнейшем авторы планируют сделать разбор ответов устойчивее.
