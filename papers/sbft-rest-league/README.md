## Что сделано в работе

- На 11 реальных REST API с 317 операциями проверили пять инструментов-участников (три промышленных инструмента и два исследовательских прототипа), а также RestTestGen — базовый уровень сравнения.
- Все инструменты оценивались по единой методике: их запускали в Docker под управлением RESTgym, метрики собирал Restats, на каждый API отводился час, каждая сессия повторялась десять раз. Учитывали обнаружение дефектов, покрытие операций и исходного кода, а также эффективность по AUC — площади под кривой изменения метрик во времени.
- AutoRestTest получил три значка — Bug Hunter, Roadrunner и Gold API Tester; EvoMaster отмечен значком Silver API Tester. По данным авторов, покрытие ветвей ни у одного инструмента не превысило 23%, а доля успешных прогонов составила 91%.
