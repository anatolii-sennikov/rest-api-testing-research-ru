## Что сделано в работе

- Предложен метод автоматической генерации и выполнения тест-кейсов для REST API только по спецификации OpenAPI 3.x: тестирование идёт по принципу чёрного ящика, без доступа к исходному коду.
- Реализованы четыре конфигурации генерации — от полностью автоматической до частичной, в которой пользователь задаёт значения параметров, если в спецификации нет нужных сведений.
- Результаты оцениваются по восьмиуровневой модели покрытия TCL0–TCL7, охватывающей входы и выходы API, и по нефункциональной метрике — среднему времени ответа.
- Метод проверен на одном API и на наборе из 30 API каталога APIs.guru в четырёх конфигурациях. По API College Football Data приведён подробный разбор; на наборе из 30 API пользовательский ввод улучшил большинство метрик, всего сгенерировано от 1 222 до 3 807 тест-кейсов.
